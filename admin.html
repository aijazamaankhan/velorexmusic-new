    Bulk Upload Products

    ✕

    Upload a CSV file to add or update products in bulk. Rows with a blank id are added as new products (auto-assigned ID); rows with an existing id update that product. Images aren't supported in bulk — add them per-product after the import.

    Required columns: title, artist, category, price
    Optional: id, language, original_price, stock, badge (hot/new/upcoming), description, music_director, track_listing, people (pipe-separated, e.g. rd-burman|amitabh-bachchan), specs_format, specs_speed, specs_label, specs_year, specs_tracks, specs_genre, specs_theme

    Password reset

    ✕

    A new temporary password has been set for …. All of their existing sessions have been invalidated.

    —
    This password is shown only once. Send it to the customer over a secure channel (a phone call, a verified support email reply, or a different secure messenger), and ask them to change it as soon as they sign in. We don't store it anywhere you can retrieve it.

    Delete account

    ✕

    This permanently deletes the account for …. Their saved addresses and sessions will be removed. Their past orders will be preserved (the user link is set to NULL). This cannot be undone.
